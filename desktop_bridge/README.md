# 闲鱼卖家客服桌面连接工具

连接工具在你的 Windows 电脑上运行，管家继续运行在服务器。客户端登录完成或手动完成滑块后，工具会读取该客户端的闲鱼会话，并自动同步到你指定的管家账号。

## 开始使用

1. 在管家的“账号管理 → 桌面客户端接入”中生成账号专属连接令牌并下载连接工具。解压到电脑上的独立文件夹。
2. 安装 [Python 3.11 或更新版本](https://www.python.org/downloads/windows/)，保留安装器默认的 Tcl/Tk 组件。双击 `start.bat`，首次运行会自动安装一个连接依赖。
3. 填写管家服务器地址、连接令牌，选择已安装的“闲鱼卖家客服” `.exe` 主程序。端口默认 `9222`。
4. 如果客户端已经运行，先正常完全退出，再点击“启动客户端并连接”。在客户端登录并手动完成平台要求的验证。
5. 工具显示同步成功后，管家会使用更新的会话重新连接。保持工具运行；后续会话变化也会自动上传，无需再复制 Cookie。

“连接已启动客户端”用于连接已经开启本机调试端口的客户端。工具不会强制退出客户端、修改安装文件或自动完成滑块。停止同步或关闭连接工具后，客户端仍可正常使用。

## 服务器地址

远程地址必须使用 HTTPS，例如 `https://butler.example.com`。连接令牌和 Cookie 都是账号凭据，工具不会将它们写入配置文件或日志。

如果服务器当前只有 HTTP，可先在 Windows 终端建立 SSH 隧道（使用你已有的 SSH 登录方式）：

```powershell
ssh -N -L 127.0.0.1:38888:127.0.0.1:38888 ubuntu@<服务器IP>
```

保持该终端运行，在连接工具中填写 `http://127.0.0.1:38888`。若本机该端口被占用，可把命令中的第一个 `38888` 换成其他空闲端口，并同步修改工具里的地址。工具只允许本机地址使用 HTTP。

## 兼容性与连接提示

客户端必须支持 Chromium 本机调试连接。不同版本的“闲鱼卖家客服”可能不开放此能力，因此本工具不保证所有版本都能连接；工具会明确显示连接失败，不会将失败当作同步成功。

- 连接失败时，确认选择的是客户端主程序，完全退出客户端后再通过工具启动，并确认本机端口未被其他程序使用。
- 已连接但等待登录时，在客户端打开闲鱼页面、完成登录及手动验证。工具只读取 `goofish.com` 范围内的会话。
- 提示令牌失效时，在账号页面重新生成令牌并重新连接。生成新令牌会使旧令牌失效；也可在账号页面撤销连接。
- 提示账号不一致时，确认客户端登录的是生成令牌时对应的闲鱼账号。

## 商品和订单通过客户端查询

在账号的「桌面客户端接入」中开启「商品和订单通过电脑客户端查询」。工具会检测客户端页面是否提供 `window.lib.mtop.request` 或 `window.mtop.request`。检测成功后，服务器的商品列表、商品详情、卖出订单列表、订单数量及订单详情查询，会交给这台电脑执行，再将结果传回服务器。

调用使用客户端页面已经加载的 SDK，由 SDK 处理 Cookie、签名和令牌续期；不会把服务器上的 HMAC-SHA1 实验算法注入客户端。只支持上述五种读取操作，服务器不能通过此通道发送任意 JavaScript、URL 或修改订单的命令。任务与配对账号绑定，查询前后会核对客户端账号。

开启后请保持电脑、客户端、连接工具在线，并打开客户端商品或订单页面。找不到 SDK、电脑离线、查询超时或出现验证时会明确失败，不自动改为服务器直连。可以在账号页面关闭此选项，恢复原来的服务器查询方式。重新生成令牌后需重新开启此选项。

此能力依赖客户端具体版本是否开放调试入口及页面 SDK。目前仅在模拟页面验证流程，尚未在真实 Windows 闲鱼卖家客服版本上实测。它不是完整接管：消息收发、自动回复、发货、退款查询等其他操作仍走原有服务器逻辑。平台仍可能要求手动验证。

调试端口仅用于本机连接，不要将它开放到公网。查询任务和结果短期保存在服务器数据库中，完成或取消后删除，超时任务在后续轮询时清理；它们不进入逻辑备份。电脑工具不保存这些数据到文件。
