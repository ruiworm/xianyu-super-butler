# 商品到手、知识库和延时发货

## 配置商品预估到手

在“商品与发货”的商品行选择“到手设置”。可以选择每件固定到手金额，或按商品成交金额计算：选择闲鱼币分润比例（可选不扣即 0%，也可选 5%、20%、30%），如有无忧卖费用再填写其比例。按比例估算时，还会按订单成交金额固定扣除 1.6% 服务费；填写每件到手金额时则不再重复扣除。所选闲鱼币分润是固定扣除比例，与买家是否使用闲鱼币无关。两种费用同时存在时，需要选择分别按成交额计算，还是先扣闲鱼币分润再计算无忧卖费用。

总览显示按当前商品规则计算的预估到手，同时列出缺少规则的订单数量。修改规则会重新估算历史订单；它不是平台实际到账金额，不能代替对账。订单里平台返回的实际金额仍以平台数据为准。

## 商品知识库

在“AI 回复”中添加商品知识库，填写资料并选择一个或多个商品。同一商品只能绑定一个知识库；多个商品可以共享同一知识库。AI 回复时会读取当前商品绑定的资料，与商品提示词一起使用。这里支持手工填写文本，不自动从文件导入或联网检索。

## 延时发货

延时发货等待中的任务会保存在数据库，服务重启并重新连接后会检查订单状态，再处理到期任务。订单状态无法确认时会保留等待，已取消、退款或已结束待发货的订单不会继续发送。

如果中断发生在开始处理发货之后，系统不会自动重试，避免密钥重复发送；请在“订单管理”的延时发货任务中核对。恢复数据库备份时，未完成的延时任务也需要人工核对，因为备份可能早于实际发货。
